# API смарт-контракта P2P

Этот API предоставляет HTTP-конечные точки для взаимодействия со смарт-контрактом P2P в блокчейне TON. Он позволяет создавать сделки, финансировать их и разрешать их через простые HTTP-запросы.

## Быстрый старт

### Предварительные требования

- Node.js (v14 или выше)
- npm или yarn
- Кошелек TON с некоторым количеством тестовых TON (для тестовой сети)
- API-ключ TON с https://toncenter.com/

### Настройка

1. Клонируйте репозиторий:
   ```bash
   git clone <url-репозитория>
   cd p2p_sc_v2
   ```

2. Установите зависимости:
   ```bash
   npm install
   ```

3. Настройте окружение:
   Создайте файл `.env` в корневом каталоге со следующим содержимым:
   ```
   WALLET_MNEMONIC="мнемоническая фраза вашего кошелька"
   MNEMONIC="мнемоническая фраза вашего кошелька"
   RPC_ENDPOINT="https://testnet.toncenter.com/api/v2/jsonRPC"
   RPC_KEY="ваш API-ключ RPC"
   CONTRACT_ADDR="адрес вашего развернутого контракта"
   WORKCHAIN="0"
   PORT=3000
   ```

4. Соберите проект:
   ```bash
   npm run build
   ```

5. Запустите API-сервер:
   ```bash
   node dist/src/server.js
   ```

API-сервер запустится и будет прослушивать порт 3000 (или порт, указанный в вашем файле `.env`).

## Использование API

### Создание сделки

```bash
curl -X POST http://localhost:3000/deal \
  -H "Content-Type: application/json" \
  -d '{
    "seller": "0:3815535e02b7fb7f06f84fce6ec68f5a3a9b6428d261d899cc875c0cd77e6182",
    "buyer": "0:61f48c6226232ad3d5da8fcb96a29a1175dad31996b55fee7e701a6b626e3bb0",
    "amount": "1000000000",
    "memo": "Оплата за услуги"
  }'
```

### Финансирование сделки

```bash
curl -X POST http://localhost:3000/fund \
  -H "Content-Type: application/json" \
  -d '{
    "memo": "Оплата за услуги",
    "value": "1000000000"
  }'
```

### Разрешение сделки

```bash
curl -X POST http://localhost:3000/resolve \
  -H "Content-Type: application/json" \
  -d '{
    "memo": "Оплата за услуги",
    "verdict": true
  }'
```

### Получение информации о сделке

```bash
curl http://localhost:3000/deal/0
```

### Получение счетчика сделок

```bash
curl http://localhost:3000/deal-counter
```

## Операции смарт-контракта

Смарт-контракт P2P поддерживает следующие операции:

1. **Создание сделки**: Создает новую сделку между продавцом и покупателем.
2. **Финансирование сделки**: Финансирует существующую сделку.
3. **Разрешение сделки**: Разрешает сделку, либо одобряя платеж продавцу, либо возвращая средства покупателю.
4. **Возврат неизвестных средств**: Возвращает неизвестные средства, которые были отправлены на контракт.
5. **Вывод комиссий**: Выводит накопленные комиссии на кошелек модератора.

Контракт взимает комиссию в размере 3% со всех транзакций.

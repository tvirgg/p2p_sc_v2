## Обзор

Смарт-контракт P2P предназначен для обеспечения одноранговых транзакций в блокчейне TON. Он позволяет создавать сделки между продавцом и покупателем, финансировать эти сделки и разрешать их (либо одобряя платеж продавцу, либо возвращая средства покупателю).

HTTP API предоставляет удобный способ взаимодействия с этим смарт-контрактом без необходимости напрямую конструировать сообщения блокчейна TON.

## Настройка окружения

Перед запуском API-сервера необходимо настроить переменные окружения в файле `.env`:

```
# Мнемоническая фраза кошелька модератора
WALLET_MNEMONIC="ваша мнемоническая фраза кошелька"

# Информация о кошельке покупателя (опционально, для тестирования)
BUYER_ADDR="адрес кошелька покупателя"
BUYER_PUBLIC_KEY="публичный ключ покупателя"
BUYER_SECRET_KEY="секретный ключ покупателя"

# Информация о кошельке продавца (опционально, для тестирования)
SELLER_ADDR="адрес кошелька продавца"
SELLER_PUBLIC_KEY="публичный ключ продавца"
SELLER_SECRET_KEY="секретный ключ продавца"

# Конечная точка TON RPC
RPC_ENDPOINT="https://testnet.toncenter.com/api/v2/jsonRPC"
RPC_KEY="ваш API-ключ RPC"

# Мнемоническая фраза кошелька модератора (то же, что и WALLET_MNEMONIC)
MNEMONIC="ваша мнемоническая фраза кошелька"

# Адрес контракта P2P
CONTRACT_ADDR="адрес вашего развернутого контракта"

# ID рабочей цепи (обычно 0)
WORKCHAIN="0"

# Порт API-сервера
PORT=3000
```

## Запуск API-сервера

Для запуска API-сервера выполните:

```bash
npm install       # Установка зависимостей (только в первый раз)
npm run build     # Сборка TypeScript-файлов
node dist/src/server.js
```

Сервер запустится и будет прослушивать порт, указанный в вашем файле `.env` (по умолчанию: 3000).

## Конечные точки API

### GET-запросы

#### Получение информации о сделке

```
GET /deal/:id
```

Получает информацию о конкретной сделке по её ID.

**Параметры:**
- `id`: ID сделки (параметр пути)

**Ответ:**
```json
{
  "amount": "1000000000",
  "isFunded": true
}
```

#### Получение счетчика сделок

```
GET /deal-counter
```

Получает текущий счетчик сделок (общее количество созданных сделок).

**Ответ:**
```json
{
  "counter": "5"
}
```

#### Получение адреса модератора

```
GET /moderator
```

Получает адрес модератора.

**Ответ:**
```json
{
  "moderator": "0:61f48c6226232ad3d5da8fcb96a29a1175dad31996b55fee7e701a6b626e3bb0"
}
```

### POST-запросы

#### Создание сделки

```
POST /deal
```

Создает новую сделку между продавцом и покупателем.

**Тело запроса:**
```json
{
  "seller": "0:3815535e02b7fb7f06f84fce6ec68f5a3a9b6428d261d899cc875c0cd77e6182",
  "buyer": "0:61f48c6226232ad3d5da8fcb96a29a1175dad31996b55fee7e701a6b626e3bb0",
  "amount": "1000000000",
  "memo": "Оплата за услуги"
}
```

**Ответ:**
```json
{
  "ok": true
}
```

#### Финансирование сделки

```
POST /fund
```

Финансирует существующую сделку. Memo должно совпадать с тем, которое использовалось при создании сделки.

**Тело запроса:**
```json
{
  "memo": "Оплата за услуги",
  "value": "1000000000"
}
```

**Ответ:**
```json
{
  "ok": true
}
```

#### Разрешение сделки

```
POST /resolve
```

Разрешает сделку, либо одобряя платеж продавцу, либо возвращая средства покупателю.

**Тело запроса:**
```json
{
  "memo": "Оплата за услуги",
  "verdict": true
}
```

Примечание: `verdict` - это булево значение, где `true` означает одобрение платежа продавцу, а `false` - возврат средств покупателю.

**Ответ:**
```json
{
  "ok": true
}
```

#### Возврат неизвестных средств

```
POST /refund-unknown
```

Возвращает неизвестные средства, которые были отправлены на контракт.

**Тело запроса:**
```json
{
  "key": "1"
}
```

**Ответ:**
```json
{
  "ok": true
}
```

#### Вывод комиссий

```
POST /withdraw
```

Выводит накопленные комиссии на кошелек модератора.

**Тело запроса:**
```json
{}
```

**Ответ:**
```json
{
  "ok": true
}
```

## Примеры использования

### Полный поток транзакции P2P

1. **Создание сделки**

```bash
curl -X POST http://localhost:3000/deal \
  -H "Content-Type: application/json" \
  -d '{
    "seller": "0:3815535e02b7fb7f06f84fce6ec68f5a3a9b6428d261d899cc875c0cd77e6182",
    "buyer": "0:61f48c6226232ad3d5da8fcb96a29a1175dad31996b55fee7e701a6b626e3bb0",
    "amount": "1000000000",
    "memo": "Оплата за услуги"
  }'
```

2. **Проверка счетчика сделок для подтверждения создания**

```bash
curl http://localhost:3000/deal-counter
```

3. **Финансирование сделки**

```bash
curl -X POST http://localhost:3000/fund \
  -H "Content-Type: application/json" \
  -d '{
    "memo": "Оплата за услуги",
    "value": "1000000000"
  }'
```

4. **Проверка, финансирована ли сделка**

```bash
curl http://localhost:3000/deal/0
```

5. **Разрешение сделки (одобрение платежа продавцу)**

```bash
curl -X POST http://localhost:3000/resolve \
  -H "Content-Type: application/json" \
  -d '{
    "memo": "Оплата за услуги",
    "verdict": true
  }'
```

### Обработка ошибок

Все конечные точки возвращают код состояния 500 с сообщением об ошибке в случае неудачи:

```json
{
  "error": "Сообщение об ошибке"
}
```

## Детали смарт-контракта

Смарт-контракт P2P поддерживает следующие операции:

1. **Создание сделки (op = 1)**: Создает новую сделку между продавцом и покупателем.
2. **Разрешение сделки (op = 2)**: Разрешает сделку, либо одобряя платеж продавцу, либо возвращая средства покупателю.
3. **Возврат неизвестных средств (op = 3)**: Возвращает неизвестные средства, которые были отправлены на контракт.
4. **Вывод комиссий (op = 4)**: Выводит накопленные комиссии на кошелек модератора.
5. **Финансирование сделки (op = 5)**: Финансирует существующую сделку.

Контракт взимает комиссию в размере 3% со всех транзакций.
